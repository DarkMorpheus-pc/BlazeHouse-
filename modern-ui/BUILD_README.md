# 🏛️ BlazeHouse — Build & Geliştirme Rehberi

Bu dosya, projenin derlenmesi ve dağıtımı için hızlı referans kılavuzudur. Detaylı bilgi için üst dizindeki [README.md](../README.md) dosyasını inceleyin.

### Hızlı Başlangıç (Arch Linux / CachyOS / Fedora / Debian)

```bash
# Bağımlılıkları yükleyin
npm install

# Geliştirme modunda çalıştırın (Tauri v2 + Rust Backend)
npm run tauri:dev

# Sadece tarayıcıda önizleme yapmak için
npm run dev

# Yayın derlemesi (Binary, Deb, RPM, AppImage)
npm run tauri:build
```
